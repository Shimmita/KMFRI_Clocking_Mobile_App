# App Icon Folder

Place your preferred app icon file here:
File path: `assets/icon/app_icon.png`

## Recommended Specifications:
- Format: PNG (.png)
- Resolution: 1024x1024 pixels (square)
- Filename: `app_icon.png`

## How to generate launcher icons:
After dropping your `app_icon.png` file in this folder, run:
```bash
flutter pub run flutter_launcher_icons
```
